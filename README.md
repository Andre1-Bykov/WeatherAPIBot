# WeatherAPIBot

Telegram-бот, который показывает текущую погоду и прогноз на 7 дней для выбранного города. Ответы — на русском языке.

## Возможности

- Текущая температура, ощущаемая температура, влажность, ветер и описание погоды.
- Прогноз на 7 дней: условия, минимальная и максимальная температура, вероятность дождя.
- Ежедневная рассылка прогноза для выбранного города в 09:00.
- Подписки и города пользователей хранятся в локальной SQLite-базе `subscriptions.sqlite3`.
- Понятные сообщения, если город не найден или API временно недоступен.

## Что понадобится

- Python 3.
- Токен Telegram-бота от [@BotFather](https://t.me/BotFather).
- API-ключ с [WeatherAPI.com](https://www.weatherapi.com/).

## Установка и запуск

Выполните команды в PowerShell из папки проекта:

```powershell
py -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirments.txt
```

Создайте в корне проекта файл `.env` и укажите в нём свои ключи:

```env
BOT_TOKEN=токен_telegram_бота
API_KEY=ключ_weatherapi
API_URL=https://api.weatherapi.com/v1
```

Запустите бота:

```powershell
python main.py
```

Не публикуйте файл `.env`: в нём находятся секретные ключи.

## Команды бота

| Команда | Действие | Пример |
| --- | --- | --- |
| `/start` или `/help` | Показать справку | `/start` |
| `/weather <город>` | Показать текущую погоду | `/weather Москва` |
| `/future-weather <город>` | Показать прогноз на 7 дней | `/future-weather Казань` |

Названия городов можно вводить на русском или английском языке.

### Подписка на рассылку

| Команда | Действие | Пример |
| --- | --- | --- |
| `/subscribe <город>` | Подписаться на ежедневную рассылку или изменить город | `/subscribe Самара` |
| `/subscription` | Проверить текущую подписку | `/subscription` |
| `/unsubscribe` | Отписаться от рассылки | `/unsubscribe` |

Рассылка прогноза на сегодня отправляется ежедневно в 09:00 по локальному времени компьютера или сервера, на котором запущен бот. Для работы рассылки бот должен быть запущен. База подписок создаётся автоматически в папке проекта; не удаляйте `subscriptions.sqlite3`, если хотите сохранить подписки.
